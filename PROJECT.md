# ONE MORE — GLM 5.3 Flash

## Purpose
An ink-brush survival browser game with journey, endless, and daily modes. This is a distinct repository from `itsnotalwin/ONE_MORE`.

## Architecture
Zero-build static HTML/CSS/vanilla JS PWA. Entry: `index.html`; gameplay, renderer, leaderboard, and bootstrap in `js/` (see `js/CONTEXT.md`), visuals in `css/`, images in `img/`, offline cache in `sw.js`.

## Cross-device Google cloud saves (4 Nov 2026)

**New additive feature:** `js/cloud-save.js` connects the game's existing Google account to a private `public.om_player_saves` table in the shared Pinpoint Supabase project. Existing progress is still saved in localStorage so offline gameplay works normally; the bridge stores only progression, scrolls/seals, run records, legacy Inkstone-key compatibility, purse/charms currency and spent/earned ink and the chosen brush, not OAuth credentials. SQL is recorded in [`CLOUD-SAVE-SCHEMA.sql`](CLOUD-SAVE-SCHEMA.sql), already applied on the shared project with owner-only RLS, no anonymous grants, compare-and-swap revisions and 8 previous cloud versions. No Pinpoint/leaderboard rows were altered. Existing source snapshot: [`backup/pre-cloud-saves-2026-11-04`](https://github.com/itsnotalwin/OneMoreGLM5.3flash/tree/backup/pre-cloud-saves-2026-11-04).

**First migration is deliberately manual:** On the PC containing your existing save, open **Settings → CLOUD SAVE → BACK UP THIS DEVICE**. On the phone, sign in with the same Google account: a genuinely blank phone auto-restores; otherwise choose **USE CLOUD SAVE** after reviewing both scroll/ink summaries. Subsequent changes auto-sync every ~14 seconds or on focus/online. If both devices changed, neither save is silently overwritten; choose the authoritative save in Settings. Choosing **KEEP THIS DEVICE** will replace the active cloud version only after explicit confirmation; SQL retains the last 8 cloud versions. Before any restore a device-local backup is stored under `__omcloud_local_backup_v1_*`; an **EXPORT DEVICE BACKUP** action downloads a JSON copy. The Settings **WIPE** only wipes local state and halts sync pending an explicit decision; it cannot erase the remote account save.

**Testing caveat:** Browser Google Auth and real PC/phone sync still require owner smoke testing on published Pages; passing JS tests, owner-RLS SQL rollbacks and Pages build are distinct. Future manual source uploads must retain `cloud-save.js`, `index.html` script order, the source hook in `lb.js` and the explicit local-wipe marker in `main.js`. The repair planner has been updated for these hooks. It emits a review-only patch artifact rather than creating branches or auto-merging.
